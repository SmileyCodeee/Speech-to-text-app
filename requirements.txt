# Use this instead of requirements.txt if you're deploying somewhere with
# more memory than a free-tier host (your own server, Streamlit Cloud paid

#   pip install -r requirements-full.txt

# CPU-only torch: on Linux, a plain `pip install torch` pulls the CUDA
# build, dragging in well over 1GB of unused nvidia-* packages even on
# hosts with no GPU at all. --extra-index-url below points pip at PyTorch's
# CPU-only wheel index (hosts builds for both Windows and Linux), avoiding
# that bloat. If you actually have an NVIDIA GPU and want CUDA acceleration,
# install the CUDA-enabled wheel first following
# https://pytorch.org/get-started/locally/ before running this file.
# ---------------------------------------------------------------------------
