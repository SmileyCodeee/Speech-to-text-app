# Hybrid architecture:
#   - ASR / structuring / keywords / summary: OFFLINE
#   - gTTS read aloud: ONLINE
#   - Export: OFFLINE
#
# Only DIRECT dependencies with loose version pins. Transitive deps are
# resolved automatically by pip.
# ──────────────────────────────────────────────────────────

# ── Abstractive summarization: REMOVED ──
# facebook/bart-large-cnn (via transformers + torch) loaded ~1.6GB into RAM
# on first use, and that memory is typically never returned to the OS for
# the rest of the process's life. This alone can exceed Render's
# free/starter plan memory limit (512MB) and cause the whole app to be
# OOM-killed. The app now uses extractive summarization only, which needs
# no ML model. To bring abstractive summarization back on a host with more
# RAM (2GB+), add back:
#   --extra-index-url https://download.pytorch.org/whl/cpu
#   transformers>=4.30.0
#   torch>=2.0.0
# and restore the "abstractive" option in app.py's summary_method radio.
